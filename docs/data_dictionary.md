# Data Dictionary

## Fare

- origin: IATA airport code
- destination: IATA airport code
- airline: airline name
- fare: normalized airfare in INR
- travel_date: intended travel date
- search_date: date on which fare was collected
- booking_window: days between search and travel date

## Route Weight

- route: origin-destination pair
- passengers: passenger traffic
- weight: passenger share
